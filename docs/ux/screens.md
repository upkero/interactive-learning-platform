# Карта экранов, переходы и правила нештатных ситуаций (UX)

## 1. Таблица переходов интерфейса (по диаграмме D24)

| Исходный экран | Маршрут | Куда ведёт (Цель) | Условие перехода |
| :--- | :--- | :--- | :--- |
| **Э1. Мои материалы** | `/materials` | **Э2. Загрузка** | Клик по кнопке «Загрузить материал» |
| **Э1. Мои материалы** | `/materials` | Зависит от `document_status` | Клик по строке документа (см. раздел 2) |
| **Э1. Мои материалы** | `/materials` | **Э3. Выбор тем** | `document.status = parsed` (переход сразу к выбору тем) |
| **Э1. Мои материалы** | `/materials` | **Э5. Прогресс** | `document.status = generating` (переход к прогрессу генерации) |
| **Э1. Мои материалы** | `/materials` | **Э6. Материал** | `document.status = done` (переход к первой опубликованной части) |
| **Э2. Загрузка** | `/upload?document={id}` | **Э3. Выбор тем** | Разбор завершён (`document.status = parsed`) |
| **Э3. Выбор тем** | `/documents/{id}/topics` | **Э4. Параметры генерации** | Выбрана хотя бы 1 тема, `cost <= remaining`, клик «Далее» |
| **Э3. Выбор тем** | `/documents/{id}/topics` | **Э2. Загрузка** | Кнопка «Назад» (переход назад всегда разрешён) |
| **Э4. Параметры генерации** | `/documents/{id}/questions?topics=id1,id2` | **Э5. Прогресс** | Успешный `POST /documents/{id}/generate` (`202 Accepted`); вопрос 1 (уровень) обязателен |
| **Э4. Параметры генерации** | `/documents/{id}/questions?topics=id1,id2` | **Э3. Выбор тем** | Кнопка «Назад» (переход назад всегда разрешён) |
| **Э5. Прогресс** | `/documents/{id}/progress` | **Э6. Материал** | По кнопке «Открыть» у части со статусом `published` (не только по `document_done`) |
| **Э5. Прогресс** | `/documents/{id}/progress` | **Э1. Мои материалы** | Кнопка «Вернуться к материалам» (в любой момент) |
| **Э5. Прогресс** | `/documents/{id}/progress` | **Э4. Параметры генерации** | **Не допускается** после запуска генерации (получен `202`) |
| **Э6. Материал** | `/parts/{id}` | **Э7. Квиз** | Клик по кнопке «Пройти тест по части» |
| **Э6. Материал** | `/parts/{id}` | **Э8. Поделиться** | Клик по кнопке «Поделиться» (модальное окно) |
| **Э7. Квиз** | `/parts/{id}/quiz` | **Э6. Материал** | Переход в любой момент (условие «—»), клик «Вернуться к конспекту» |
| **Э6. Материал** | `/parts/{id}` | **Э5. Прогресс** | Переход к прогрессу генерации (если есть части не в `published`) |
| **Э6. Материал** | `/parts/{id}` | **Э1. Мои материалы** | Кнопка «Вернуться к материалам» |

## 2. Открытие документа из списка (Э1) по `document_status`

| `document_status` | Целевой экран и маршрут | Поведение |
| :--- | :--- | :--- |
| `uploaded` | **Э2** (`/upload?document={id}`) | Отображается карточка загрузки с кнопкой «Повторить разбор» |
| `parsing` | **Э2** (`/upload?document={id}`) | Отображается карточка разбора (`ParsingCard`) с подпиской на SSE разбора |
| `parsed` | **Э3** (`/documents/{id}/topics`) | Открывается дерево тем для выбора |
| `generating` | **Э5** (`/documents/{id}/progress`) | Подключение к SSE-потоку генерации |
| `done` | **Э6** (`/parts/{part_id}`) | Открывается первая опубликованная часть материала |
| `failed` | **Э3** (`/documents/{id}/topics`) | Открывается выбор тем — можно запустить генерацию заново |

---

## 3. Редиректы при прямом заходе по ссылке на «чужой» шаг мастера

Если пользователь открывает URL шага мастера, который не соответствует актуальному `document_status` документа на сервере, выполняется принудительный `router.replace`:

* Документ в `uploaded` / `parsing` → любой заход на `/topics`, `/questions`, `/progress`, `/parts/{id}` редиректит на `/upload?document={id}`.
* Документ в `parsed` → заход на `/questions`, `/progress`, `/parts/{id}` редиректит на `/documents/{id}/topics`.
* Документ в `generating` → заход на `/topics`, `/questions`, `/parts/{id}` редиректит на `/documents/{id}/progress`.
* Документ в `done` → заход на `/topics`, `/questions`, `/progress` редиректит на `/parts/{part_id}` (первая опубликованная часть).
* Документ в `failed` → заход на `/questions`, `/progress`, `/parts/{id}` редиректит на `/documents/{id}/topics` (переход назад на `/upload?document={id}` разрешён).

## 4. Маршруты экранов (итоговый свод)

| Экран | Маршрут | Примечание |
| :--- | :--- | :--- |
| **Э1. Мои материалы** | `/materials` | — |
| **Э2. Загрузка** | `/upload?document={id}` | `document` — query-параметр для возврата к конкретному документу |
| **Э3. Выбор тем** | `/documents/{id}/topics` | — |
| **Э4. Параметры генерации** | `/documents/{id}/questions?topics=id1,id2` | Состояние мастера (выбранные темы) хранится в URL через query-параметр `topics` |
| **Э5. Прогресс** | `/documents/{id}/progress` | — |
| **Э6. Материал** | `/parts/{id}` | Часть материала, не весь документ |
| **Э7. Квиз** | `/parts/{id}/quiz` | — |
| **Э8. Поделиться** | — | Модальный диалог поверх Э6 или Э1, доступен только владельцу (`role = owner`) |

---

## 5. Доступ к экрану «Поделиться» (Э8)

Экран **Э8** реализован как модальный диалог, открываемый поверх **Э6** (Материал) или **Э1** (Мои материалы).

* Доступно только владельцу документа (`role = owner`).
* Для пользователей с `role = shared` кнопка «Поделиться» скрыта / недоступна.
