# Прототип мастера генерации (Э2 -> Э3 -> Э4 -> Э5)

## 1. Хранение состояния мастера в URL
Состояние мастера синхронизируется с query-параметрами адресной строки через `useSearchParams` и `router.replace`:
* **Э2 (Загрузка / Разбор):** `/[locale]/upload?doc={documentId}`
* **Э3 (Выбор тем):** `/[locale]/documents/{documentId}/topics?topics=t1,t2,t5`
* **Э4 (Три вопроса):** `/[locale]/documents/{documentId}/questions?topics=t1,t2,t5&level=novice&depth=standard&goal=exam`
* **Э5 (Прогресс):** `/[locale]/documents/{documentId}/progress`

Перезагрузка страницы (F5) или прямой переход по ссылке полностью восстанавливает выбранные темы и ответы формы.

---

## 2. Пошаговый сценарий по кликам

1. **Э2 (`/upload`):**
   * Пользователь перетаскивает файл в Dropzone или вставляет ссылку Google Docs и нажимает «Импортировать».
   * Отображается `ParsingCard` с прогрессом разбора.
   * По событию готовности разбора (`topics_required`) выполняется переход на Э3.
2. **Э3 (`/documents/[id]/topics`):**
   * Отображается дерево тем `TopicTree` с чекбоксами и превью частей `PlanPreview`.
   * При каждом переключении чекбокса (с дебаунсом 300 мс) пересчитывается стоимость `cost` в генерациях.
   * Клик по кнопке «Далее» переводит на Э4 с сохранением выбранных `topics` в URL.
3. **Э4 (`/documents/[id]/questions`):**
   * Радиогруппы `level`, `depth`, `goal` предзаполняются значениями из профиля пользователя (`useMe().last_answers`).
   * Чекбокс уведомления на почту обновляет настройку через `PATCH /me`.
   * В блоке подтверждения отображается `questions.confirmSpend` (стоимость к списанию и остаток).
   * Клик по «Запустить генерацию» отправляет `POST /documents/{id}/generate` и переводит на Э5.
4. **Э5 (`/documents/[id]/progress`):**
   * Отображаются: таймер ETA по формуле, живой журнал `StageLog`, карточки частей `PartCards` и список терминов `KeyTerms`.
   * При получении финального события `document_done` активируется переход на Э6 (`/documents/[id]`).

---

## 3. Нештатные ветки в прототипе

* **Ветка «Не хватает генераций» (Э3 / Э4):**
  * Если `cost > quota.remaining`, строка стоимости подсвечивается красным, выводится предупреждение `topics.quotaWarning`, а кнопка перехода/запуска переводится в `disabled`.
* **Ветка «Часть упала» (Э5):**
  * Если для одной из частей приходит событие ошибки (`part_status = failed`), её карточка в `PartCards` меняет бейдж на «Сбой генерации» и рендерит кнопку «Повторить часть» (`retryPartButton`) без повторного списания квоты, пока остальные части продолжают генерироваться.
