# Корпус и предварительный выбор примитивов

Корпус подготовлен для SCRUM-115. `corpus/manifest.yaml` записан в синтаксисе
JSON — это допустимое подмножество YAML и позволяет запускать проверку без
дополнительных зависимостей. Главы содержат атрибуцию и ссылку на источник;
отдельные иллюстрации остаются ссылками на исходный материал. Для хранения
материалов без открытой лицензии зарезервирован игнорируемый `corpus/private/`;
текущие 20 материалов его не требуют.

Из папки `backend`:

```sh
uv run python -m evals.coverage --check-manifest
uv run python -m evals.coverage
uv run pytest -q tests/unit/test_evals_coverage.py
```

Вторая команда полностью перезаписывает `reports/coverage.md`. Входы можно
указать через `--manifest`, `--intents`, `--labels`, `--second` и `--output`;
неполные или несогласованные данные приводят к ошибке, а не к частичному отчёту.

## Происхождение и ограничения данных

- SCRUM-116 не выполнялся: здесь нет `export_intents.py`, данных MainPass,
  идентификатора промпта, модели или оценки стоимости.
- `hypotheses.jsonl` — 40 идей AI, по две на главу; `source_line` и
  `source_quote` указывают на текст в соответствующей главе. Идеи и разметка описывают
  потенциальные потребности, а не фактические запросы модели.
- `labels.csv` — первичная разметка AI. `labels_second.csv` — повторный проход
  того же AI по восьми строкам (`seed=42`), не независимая ручная разметка.
  Подробные эскизы кандидатов и примеры — в `corpus/LABELING.md`.
- `cov` считает только `full`, `cov⁺` — `full` и `extend`; `other:*` остаётся в
  знаменателе, `not_needed` исключается. `cov_d` считается как `cov⁺` по
  дисциплине. При отсутствии записей по дисциплине возвращается `—`.
- Жадный выбор на каждом шаге максимизирует прирост `cov⁺`; при равенстве
  выбирает меньшую трудоёмкость `S`, `M`, `L`, затем ID. При нулевом приросте
  останавливается. Данные и результат не подтверждают реальные пороги покрытия.

`docs/adr/0013-proposed-mvp-primitives.md` — предложение, а не принятое решение.
Для исходных критериев SCRUM-117/118 требуются независимые разметчики, реальные
намерения и решение лида. Записи в Jira этими командами не меняются.
