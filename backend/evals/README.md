# Корпус и предварительный выбор примитивов

Манифест `corpus/manifest.yaml` — YAML: в нём источники, лицензии, ревизии и
контрольные суммы глав, а также описания и трудоёмкость кандидатов. Закрытые
материалы хранятся в игнорируемом `corpus/private/`. Размеры глав различаются
сознательно: сохранены целые материалы источников; перед реальным прогоном нужно
учесть стоимость и нарезать их штатным механизмом на части.

Из `backend`:

```sh
uv run python -m evals.coverage --check-manifest
uv run python -m evals.coverage
uv run pytest -q tests/unit/evals/test_coverage.py
```

Расчёт перезаписывает `reports/coverage.md` и печатает таблицу. Пути можно
передать через `--manifest`, `--intents`, `--labels`, `--second`, `--output`.
Для реального прогона передайте `--intents путь/intents.jsonl` и соответствующий
CSV; необязательную вторую разметку передают через `--second`. Модель не вызывается
скриптом. JSONL поддерживает заголовок с `prompt_sha`, `model`, `provenance` и
строки `intent_id`, `chapter_id`, `intent`, `source_span`. Для реальных данных
по умолчанию используется `main_pass`; искусственные помечаются `hypothetical`.

## Происхождение и ограничения

- SCRUM-116 не выполнялся: `hypotheses.jsonl` содержит 40 идей AI, а не
  выгрузку MainPass. `source_span` в большинстве строк — заголовок раздела,
  а не конкретный фрагмент текста; `source_line` проверяется по главе.
- `labels.csv` и повторная разметка восьми строк из `labels_second.csv`
  подготовлены одним AI, поэтому не являются независимой оценкой согласия.
- `cov` считает `full`, `cov⁺` — `full` и `extend`; `other:*` остаётся в
  знаменателе и рассматривается при выборе (трудоёмкость по умолчанию `L`),
  `not_needed` исключается. `cov_d` — `cov⁺` для дисциплины.
- При равном приросте выбирается меньшая трудоёмкость, затем ID. При нулевом
  приросте выбор останавливается. Гипотетические метрики не подтверждают пороги.

`docs/adr/0013-proposed-mvp-primitives.md` — предложение до ревью лида. Записи
в Jira этими командами не меняются.
