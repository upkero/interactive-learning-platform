## Activation functions

The activation function decides how strong a neuron's output is. A
rectified linear unit (ReLU) passes positive values unchanged and turns
negative values into zero. The sigmoid squeezes the output into a bounded
range between zero and one.

A network with only linear layers is still one linear transformation,
whatever its depth. The non-linear activation between layers is what lets
a deep network represent curved decision boundaries.
