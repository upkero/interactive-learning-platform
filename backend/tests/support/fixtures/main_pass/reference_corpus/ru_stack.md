## Стек вызовов

Стек вызовов хранит сведения об активных вызовах функций. Когда функция вызывает другую функцию, новая запись помещается на вершину стека. После завершения вызова его запись удаляется, и управление возвращается вызывающей функции.

Рекурсия возникает, когда функция вызывает саму себя. Базовый случай задаёт условие остановки, а рекурсивный вызов приближает вычисление к этому условию. Если базовый случай не достигается, стек может переполниться.
